# Teste com pessoas (Fase 5)

Critério da Fase 5: "teste com pelo menos 3 pessoas registrado no LOG". O GDD pede, nos próximos passos: "testar com amigos, ajustar economia e só então expandir".

## Preparação (5 minutos)

- Build de Windows (`build/windows/PescanoLago.exe`) ou build web no celular (ver `docs/celular-web.md`).
- Um save novo para cada pessoa: rode o jogo com `--new-game` (no PC) ou abra a build web numa aba anônima.
- Não explique os controles antes. Observe e anote; só ajude se a pessoa ficar travada por mais de 1 minuto.

## Roteiro (15 a 20 minutos por pessoa)

1. A pessoa abre o jogo e chega a Porto Manso. **Observe:** entende o que fazer? Acha o botão "Pescar"?
2. Joga o **dia 1** inteiro. **Observe:** consegue pilotar até as ondulações? Entende mirar e carregar o lançamento? Fisga na hora? Entende a barra de tensão?
3. Volta a Porto Manso. **Observe:** entende as estrelas e o "dia 2 liberado"? Visita as lojas? Compra alguma coisa?
4. Joga o **dia 2** (ou repete o 1).
5. Responde às perguntas abaixo.
